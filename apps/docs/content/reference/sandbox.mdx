The root entry exports `createSandbox`, `connectSandbox`, `listSandboxes`, `reapSandboxes`, `SandboxError`, and the types on this page. Providers live on subpaths: `/local`, `/e2b`, `/vercel`, `/daytona`, `/memory`. Agent tools live on `/ai`, `/mastra`, and `/openai`. The adapter contract is on `/provider` and the conformance suite on `/testing`.

## `createSandbox(provider, options?)`

Creates a sandbox, or with `key`, finds the existing one first. Guide: [Sandboxes and keys](/concepts/sandboxes-and-keys).

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { e2b } from "@opencoredev/sandbox-sdk/e2b";

await using box = await createSandbox(e2b(), { key: "user:123", timeoutMs: 60 * 60_000 });
```

### Parameters

- `provider`: a provider from a subpath factory, such as `e2b()`.
- `key?: string`: get-or-create key. `box.created` tells you which happened.
- `locator?: { get(key), set(key, id), delete?(key) }`: your own key store, for exact keys on best-effort providers.
- `size?: "small" | "medium" | "large" | { cpu, memoryMb, diskGb }`: machine size. Fails with `unsupported` if the provider can't honor it. Guide: [Machine size and network](/guides/machine-size-and-network).
- `env?: Record<string, string>`: environment for every command.
- `secrets?: Record<string, string>`: set as environment variables and redacted from all output, logs, and errors.
- `network?: "all" | "none" | { allow: string[] }`: defaults to `"all"`. Fails with `unsupported` if the provider can't enforce it.
- `ports?: number[]`: ports to expose. Required by Vercel, ignored elsewhere.
- `idleTimeoutMs?: number`: stop or pause after this long idle.
- `timeoutMs?: number`: hard maximum lifetime.
- `labels?: Record<string, string>`: your labels. The SDK adds `sandbox-sdk`.
- `from?: string`: a snapshot ID to start from.
- `signal?: AbortSignal`: abort creation. A sandbox that arrives after the abort is destroyed.

### Returns

`Promise<Sandbox>`, typed per provider. Throws `SandboxError` when creation fails.

## `connectSandbox(provider, id)`

Attaches to an existing sandbox by native ID. Throws `not_found` if it doesn't exist.

## `listSandboxes(provider, options?)`

Returns `{ id, key?, labels, state, createdAt }[]` for sandboxes this SDK created. `labels` filters the list. `state` is `"running"`, `"paused"`, or `"stopped"`. `createdAt` is epoch milliseconds.

## `reapSandboxes(provider, options?)`

Destroys matching sandboxes and returns the count. Options: `olderThanMs?`, `labels?`, `idleOnly?`. Guide: [Lifecycle and cleanup](/concepts/lifecycle-and-cleanup#find-and-reap-sandboxes).

### `run(command, options?)`

Returns a `RunHandle`: await it for a `RunResult`, or iterate it for `{ stream, text }` chunks. Guide: [Running commands](/concepts/running-commands).

| Option | Default |
| --- | --- |
| `cwd?: string` | `/workspace` |
| `env?: Record<string, string>` | none |
| `timeoutMs?: number` | `120_000` |
| `maxOutputBytes?: number` | 1 MB per stream |
| `stdin?: string` | closed |
| `signal?: AbortSignal` | none |

`RunResult` is `{ ok, exitCode, stdout, stderr, output, durationMs, truncated, timedOut, cwd, command }`. A non-zero exit, a timeout, and an abort all resolve. None of them throws.

### `` $`command` ``

A tagged template that shell-escapes every interpolated value and returns a `RunHandle`. Chain `.cwd(path)`, `.env(vars)`, and `.timeout(ms)`.

### `start(command, options)`

Starts a background process and resolves when it is ready. Guide: [Processes and previews](/concepts/processes-and-previews).

- `name: string`: required, unique per sandbox.
- `cwd?: string`
- `env?: Record<string, string>`
- `ready?: { port } | { http: { port, path? } } | { log: RegExp }`
- `readyTimeoutMs?: number`

Throws `process_exited` if the process exits before it is ready.

### `ProcessHandle`

| Member | What it does |
| --- | --- |
| `name`, `status`, `ready`, `url` | Current state. `url` is set when `ready` named a port. |
| `lines({ after? })` | Async iterable of `{ text, stream, cursor }` |
| `logs({ after?, maxBytes? })` | One page: `{ text, nextCursor, truncated }` |
| `stop({ graceMs? })` | SIGTERM, then SIGKILL. Idempotent. |
| `restart()` | Stops and starts the same command |
| `wait()` | Resolves `{ exitCode, signal }` on exit |

### `process(name)`, `processes()`

`process(name)` returns the handle for a named process from any client. `processes()` returns `{ name, command, status, pid, ports, startedAt, exitCode }[]`.

### `preview(port, options?)`

Returns `{ url, headers?, expiresAt? }`. Options: `path?`, `waitMs?`. With `waitMs`, the URL is checked from outside before it returns.

### `usage()`

Returns `{ createdAt, runningMs, commands, bytesOut }` plus any cost fields the provider reports.

### `close()`, `destroy()`, `[Symbol.asyncDispose]()`

`close()` detaches and leaves the sandbox running. `destroy()` deletes it. `await using` calls `close()` when the sandbox has a key and `destroy()` otherwise.

### Optional capabilities

Present on the type only when the provider supports them.

| Method | Returns |
| --- | --- |
| `pause()`, `resume()` | `Promise<void>` |
| `snapshot()` | `Promise<{ id }>`. Pass `id` as `from` to `createSandbox`. |
| `terminal({ cols, rows })` | A PTY with `write`, `resize`, `onData`, `close` |

## Files

Relative paths resolve against `/workspace`. Guide: [Files and git](/concepts/files-and-git).

| Method | Returns |
| --- | --- |
| `read(path, { as? })` | `string`, or `Uint8Array` with `as: "bytes"` |
| `write(path, data)` or `write(record)` | `void`. Creates directories. |
| `edit(path, { find, replace })` | `void`. Throws `edit_not_found` or `edit_not_unique`. |
| `list(path?, { recursive?, glob? })` | `{ path, type, size, modifiedAt }[]` |
| `stat(path)` | `{ path, type, size, modifiedAt }` |
| `exists(path)` | `boolean` |
| `remove(path, { recursive? })` | `void` |
| `upload(localDir, remoteDir, { ignore? })` | `void` |
| `download(remoteDir, localDir)` | `void` |
| `search(query, { path?, glob?, maxMatches? })` | `{ path, line, text }[]` |
| `watch(path, callback, { recursive? })` | A function that stops watching |
| `mark(name?)` | The checkpoint name |
| `changes({ since? })` | `{ added, modified, removed, patch }` |
