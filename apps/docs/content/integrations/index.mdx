Sandbox SDK is a server-side TypeScript library with no framework dependency. These pages show how it fits into the tools you already use: which subpath to import, where the sandbox is created, and where keys stay.

Every integration follows the same rules. Provider keys stay on the server. A sandbox that should outlive one request gets a `key`. A sandbox you're done with is destroyed, or reaped later.

## Agent frameworks

Each framework gets `sandboxTools(box)` from its own subpath. The tools, their output, and their options are identical across frameworks, so switching frameworks doesn't change what the model sees.

Using another framework? `@opencoredev/sandbox-sdk/tools` exports `createSandboxTools` and `toolSchemas`, the Zod schemas behind every tool. Convert them with `z.toJSONSchema`. See [Agent tools](/reference/agent-tools#other-integrations).
