A provider is where sandboxes actually run. You pick one by importing its factory from a subpath and passing it to `createSandbox`. The rest of your code stays the same when you switch.

Each cloud provider uses that company's own SDK with your credentials. Install the SDK next to Sandbox SDK. It loads on the provider's first operation, so unused providers cost nothing.

Not sure where to start? [Choose a provider](/getting-started/choose-a-provider) maps common needs to a provider.

Memory accepts a network policy because it has no network to open. It records the setting and enforces nothing.

## Key mode in one sentence

Exact providers guarantee that concurrent `createSandbox` calls with the same `key` land on one sandbox. Best-effort providers find sandboxes by searching, so two requests at the same moment can create two. Read [Exact and best-effort keys](/concepts/sandboxes-and-keys#exact-and-best-effort-keys) for the fix.
