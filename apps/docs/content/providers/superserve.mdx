---
title: Superserve
description: Run Firecracker microVMs on Superserve. Pause and resume, snapshots, and authenticated HTTPS previews.
---

`superserve()` runs each sandbox as a Firecracker microVM on [Superserve](https://docs.superserve.ai/sandbox/create) through the official `@superserve/sdk`.

## Install

```package-install
npm i @opencoredev/sandbox-sdk@next @superserve/sdk
```

The adapter needs `@superserve/sdk` 0.11.4 or later. Set `SUPERSERVE_API_KEY` on your server, and keep it out of browser bundles.

## Quickstart

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { superserve } from "@opencoredev/sandbox-sdk/superserve";

await using box = await createSandbox(superserve({ installPython: true }));
const result = await box.run("node --version");
console.log(result.stdout);
```

The default template, `superserve/node-22`, has no Python, which the adapter needs. `installPython: true` installs it on first use. `await using` deletes the VM when the block ends.

## What it supports

| Feature | Support | Notes |
| --- | --- | --- |
| Commands and streaming | Partial | Output arrives when the command finishes |
| Files | Yes | |
| Background processes | Yes | |
| Preview URLs | Yes | Private; send the returned header |
| Pause and resume | Yes | VM state survives |
| Snapshots | Yes | |
| Machine size | No | Set by the template |
| Network policy | No | Only `"all"` |
| Hard lifetime (`timeoutMs`) | No | |
| Idle timeout (`idleTimeoutMs`) | No | |
| Keys | Best-effort | Found by metadata lookup |
| Terminal | No | |

## Run commands

Await `box.run` for the result. Iterating works too, but output is read from guest disk after the command exits, so chunks arrive together at the end.

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { superserve } from "@opencoredev/sandbox-sdk/superserve";

await using box = await createSandbox(superserve({ installPython: true }));
const result = await box.run("ls -la", { cwd: "/workspace", timeoutMs: 30_000 });
console.log(result.exitCode, result.stdout);

for await (const chunk of box.run("echo one; echo two")) {
  process.stdout.write(chunk.text);
}
```

## Files

Relative paths resolve against `/workspace`.

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { superserve } from "@opencoredev/sandbox-sdk/superserve";

await using box = await createSandbox(superserve({ installPython: true }));
await box.files.write("notes/todo.txt", "ship the docs\n");
console.log(await box.files.read("notes/todo.txt"));
console.log(await box.files.list("notes"));
```

## Background processes and previews

No ports to declare. `box.preview(port)` publishes the port as private and returns the auth header in `preview.headers`. Send it with every request. Ports must be between 1024 and 65535, except 49983.

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { superserve } from "@opencoredev/sandbox-sdk/superserve";

await using box = await createSandbox(superserve({ installPython: true }));
await box.start("python3 -m http.server 3000", { name: "web", ready: { port: 3000 } });
const preview = await box.preview(3000, { waitMs: 10_000 });
const response = await fetch(preview.url, { headers: preview.headers });
console.log(response.status);
```

## Pause, resume, and snapshots

Pause and resume keep the VM state. `snapshot()` returns an ID that `from` accepts.

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { superserve } from "@opencoredev/sandbox-sdk/superserve";

await using box = await createSandbox(superserve({ installPython: true }), { key: "user:123" });
await box.pause();
await box.resume();

const { id } = await box.snapshot();
await using copy = await createSandbox(superserve(), { from: id });
```

Snapshots outlive their source; delete them with the native `Snapshot.deleteById(id)`.

## Size, network, and lifetime

Resources come from the template. `size`, `network` other than `"all"`, `idleTimeoutMs`, and `timeoutMs` fail with `unsupported` before a VM is allocated.

```ts
import { createSandbox, SandboxError } from "@opencoredev/sandbox-sdk";
import { superserve } from "@opencoredev/sandbox-sdk/superserve";

try {
  await createSandbox(superserve(), { size: "large" });
} catch (error) {
  if (error instanceof SandboxError && error.code === "unsupported") {
    console.log("Pick a template with the machine you need.");
  }
}
```

## Configuration

| Option | Type | Default | Env var |
| --- | --- | --- | --- |
| `apiKey` | `string` | | `SUPERSERVE_API_KEY` |
| `baseUrl` | `string` | `https://api.superserve.ai` | `SUPERSERVE_BASE_URL` |
| `template` | `string` | `"superserve/node-22"` | |
| `installPython` | `boolean` | `false` | |
| `requestTimeoutMs` | `number` | `90_000` | |

A template needs Git, tar, and `nohup`, plus Python 3 unless `installPython` is on. Installing Python needs root and package-repository access and slows the first operation. For fast starts, build a template with Python 3 included; the repo's benchmark has one in `bench/templates/superserve/build.ts`. `box.native` is the SDK's `Sandbox` object.

## Limitations

- Keys are best-effort. Pass a [`locator`](/concepts/sandboxes-and-keys#exact-and-best-effort-keys) for exact get-or-create.
- No sizes, network restrictions, idle timeouts, hard lifetimes, or terminals.
- Command output isn't live.
- Connecting to a paused VM resumes it.

## How it works

- Commands run under a guest supervisor in their own process group. A timeout or abort triggers a separate cancellation check, and an unconfirmed kill returns `outcome_unknown`.
- If the template sets a native auto-pause timeout, the adapter clears it, because it is an active-time window, not a hard lifetime.
- Listing uses native metadata and doesn't wake VMs.
- A failed snapshot reports `outcome_unknown` with the snapshot name. List the source's snapshots before retrying.
