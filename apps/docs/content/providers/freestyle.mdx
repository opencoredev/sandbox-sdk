`freestyle()` runs persistent Linux VMs through [Freestyle](https://www.freestyle.sh/docs). It uses the current `freestyle` package, version 0.2.20 or later. The older `freestyle-sandboxes` package has a different API and is not supported.

## Installation

```package-install
npm i @opencoredev/sandbox-sdk freestyle
```

Set `FREESTYLE_API_KEY` on your server. Keep it out of browser bundles.

## Basic usage

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { freestyle } from "@opencoredev/sandbox-sdk/freestyle";

await using box = await createSandbox(freestyle(), { network: "none" });
console.log((await box.run("uname -a")).stdout);
```

## Configuration

`freestyle({ apiKey, baseUrl, snapshotId, requestTimeoutMs })` accepts an explicit key, API endpoint, base snapshot, and request deadline. The default snapshot is `freestyle/ubuntu`. The request deadline defaults to 30 seconds and applies to each HTTP request and native guest command. Freestyle may poll background requests; the setting is not a total deadline for an entire create or snapshot operation.

Guest operations run as `root`. Images need Python 3, Git, GNU tar, and `nohup`; creation checks these tools and creates `/workspace`. Explicit `size` presets and custom resources fail with `unsupported`. To select a machine configuration, supply a base snapshot through `snapshotId`; the adapter does not promise an SDK size mapping.

## Keys and labels

Key mode is **best-effort**. Native metadata marks SDK VMs. The full key and labels live in `/var/lib/sandbox-sdk.json`, avoiding the service's short metadata-value limit. Listing paginates the VM API and reads each SDK VM's marker, which can wake a sleeping VM. Keep that file intact and never store secrets in labels.

A fresh adapter can find the same VM. Use a [`locator`](/concepts/sandboxes-and-keys#exact-and-best-effort-keys) when concurrent callers need exact get-or-create.

## Network

- `network: "all"`, also the default, creates one outbound rule from the VM to public destinations. Freestyle's platform restrictions, including outbound mail, still apply.
- `network: "none"` creates no firewall or outbound TLS rules and attaches no VPC. An empty `{ allow: [] }` has the same behavior.
- Nonempty allow lists fail with `unsupported`. The current firewall matches addresses and resource identities; TLS hostname rules authorize specific protocols. The adapter does not treat either as a general host allow list.

The adapter reads back the VM's firewall rules, VPCs, and TLS grants. A broader policy makes creation fail and deletes the VM.

Freestyle's platform ingress, including mapped HTTPS and SSH, remains available under `"none"`. This option blocks outbound network access; it does not disable previews.

## Idle and lifetime limits

`idleTimeoutMs` maps to the native network-activity idle timer, rounded up to whole seconds. `timeoutMs` maps to `ttlSeconds`, rounded down to whole seconds so deletion is never later than requested. Hard lifetimes below one second fail with `unsupported`. The adapter reads both settings back and fails closed if the service does not confirm them.

Omitting the idle timeout requests no idle pause. Your plan can still reclaim unused VMs under its retention policy. `box.close()` detaches; `box.destroy()` deletes the VM and its dependent network and TLS rules.

## Commands and files

Freestyle's `vm.exec()` returns buffered output. The adapter emits chunks after each native call completes. User commands run under a detached Python supervisor that spools stdout and stderr in arrival order. Each polling call returns at most three 16 KiB records, so a large command cannot make the native client buffer its entire output.

The supervisor closes stdin and owns the process group. Timeout or abort kills the complete group before the adapter settles. If cancellation cannot be confirmed, it deletes the VM; an unconfirmed deletion reports `outcome_unknown`.

Environment values and stdin travel through a private `0600` file inside a `0700` directory. Values never become command text or arguments. Creation environment values also live in a root-only `0600` file so fresh handles recover their environment. Snapshots capture that file, including secrets. Treat snapshots as sensitive.

Uploads use `vm.fs.writeFile()` with mode `0600`. File reads are bounded guest reads; metadata, recursive directories, and removal use Python. Guest output spooling uses disk proportional to command output.

## Pause and snapshots

`pause()` freezes the VM with memory. `resume()` calls native `start()`. `snapshot()` captures memory and disk; pass its ID as `from` to create another VM. The new VM gets fresh SDK identity and the requested network rules. The adapter has no separate fork method: use snapshot plus `from`, or the typed native API for other operations.

## Previews

`box.preview(port)` creates a public HTTP TLS rule at a random `sdk-<uuid>.style.dev` domain, targeting the VM and port. Bind the guest server to `0.0.0.0`. No ports need to be declared up front. The adapter caches the domain for that port while the provider instance lives; reconnecting through a new instance can create another domain.

These URLs are public and require no extra headers. Protect sensitive applications yourself. The current SDK uses `tls.rules.create()`, replacing the older domain-mappings API. Deleting the VM deletes its dependent TLS rules.

## Environment variables

| Variable | Purpose |
| --- | --- |
| `FREESTYLE_API_KEY` | Required API key, overridden by `apiKey` |

## API reference

`freestyle(options?)` returns a provider with `"pause"`, `"snapshot"`, and `"network-policy"`. `box.native` is the official SDK's typed `Vm` handle.

## Limitations

- No explicit sizes, nonempty host allow lists, or SDK terminals.
- Idle time measures network activity, not guest CPU use.
- Snapshot and creation calls can continue as native background requests if a connection fails. An uncertain create reports `outcome_unknown`; inspect your account before retrying.
- Listing can wake VMs. Snapshots retain their guest environment and any running processes.
- Live tests require both `SANDBOX_FREESTYLE_LIVE=1` and `FREESTYLE_API_KEY`.
