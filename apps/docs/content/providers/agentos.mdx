---
title: Rivet agentOS
description: Run command and file tasks locally in V8 and WebAssembly, without Docker or a cloud account. Exact in-process keys and host allow lists.
---

`agentos()` runs each sandbox in [Rivet agentOS](https://rivet.dev/agentos/docs/embedded), a small virtual OS inside your application process. For real Linux, background processes, or previews, use [Local](/providers/local) with Docker.

## Install

```package-install
npm i @opencoredev/sandbox-sdk@next @rivet-dev/agentos-core@0.4.1
```

No account, API key, or Docker daemon. Rivet publishes sidecars for Linux glibc and macOS on x64 and arm64; native Windows is not supported.

## Quickstart

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { agentos } from "@opencoredev/sandbox-sdk/agentos";

await using box = await createSandbox(agentos());
await box.files.write("hello.cjs", "console.log(6 * 7)");
const result = await box.run("node hello.cjs");
console.log(result.stdout);
```

This prints `42`. `await using` disposes the VM when the block ends.

## Run commands

Await `box.run` for the result, or iterate it to stream output as it arrives. Command timeouts and cancellation work.

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { agentos } from "@opencoredev/sandbox-sdk/agentos";

await using box = await createSandbox(agentos());
const result = await box.run("ls -la", { cwd: "/workspace", timeoutMs: 30_000 });
console.log(result.exitCode, result.stdout);

for await (const chunk of box.run("echo one; echo two")) {
  process.stdout.write(chunk.text);
}
```

It does not boot Linux. Pure JavaScript npm packages can work; native addons and arbitrary Linux binaries don't.

## Files

Relative paths resolve against `/workspace`.

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { agentos } from "@opencoredev/sandbox-sdk/agentos";

await using box = await createSandbox(agentos());
await box.files.write("notes/todo.txt", "ship the docs\n");
console.log(await box.files.read("notes/todo.txt"));
console.log(await box.files.list("notes"));
```

## Background processes and previews

`box.start()` and `box.preview()` throw `unsupported`. Listeners stay inside the VM. Reach a guest HTTP server through the native API:

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { agentos } from "@opencoredev/sandbox-sdk/agentos";

await using box = await createSandbox(agentos());
const response = await box.native.network.httpRequest({ port: 3000, path: "/" });
console.log(response.status);
```

Start the server with `box.native.process.spawn()`.

## Pause, resume, and snapshots

agentOS has no pause, resume, or snapshots, and the methods don't exist on its sandbox type. Code that accepts any provider can check first:

```ts
import { createSandbox, hasCapability } from "@opencoredev/sandbox-sdk";
import { agentos } from "@opencoredev/sandbox-sdk/agentos";

await using box = await createSandbox(agentos());
if (hasCapability(box, "pause")) await box.pause();
```

## Size, network, and lifetime

`size`, `idleTimeoutMs`, and `timeoutMs` fail with `unsupported`. `network: "none"` denies guest egress, and an allow list accepts literal host names, with no wildcards or URLs.

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { agentos } from "@opencoredev/sandbox-sdk/agentos";

await using box = await createSandbox(agentos(), {
  network: { allow: ["registry.npmjs.org"] },
});
```

## Configuration

| Option | Type | Default | Env var |
| --- | --- | --- | --- |
| `gitPackagePath` | `string` | Rivet's pinned Git package, downloaded | |

Pass a trusted local `.aospkg` file to work offline. `box.native` is the typed `AgentOs` VM.

## Limitations

- A virtual OS, not a Linux kernel.
- No SDK background processes, previews, pause, snapshots, sizes, timeouts, or terminals.
- Git clone, commit, status, and file checkpoints work. Git push stalls in agentOS 0.4.1.
- Files and keys last only as long as your application process.

## How it works

- Commands run in agentOS's virtual process table. JavaScript runs in V8 isolates, and shell tools run as WebAssembly over a shared virtual file system.
- The first sandbox downloads Rivet's Git package (about 18 MB) and checks its pinned SHA-256 digest. Rivet caches it by digest.
- All factories in one process share a registry, so keys, reconnect, list, and reap work across them. Another process has its own.
- The Linux x64 sidecar takes about 144 MiB on disk.
