---
title: Boat
description: Run persistent Ubuntu VMs for long-running agents on Boat. Size presets, durable background processes, and cookie-authenticated previews.
---

`boat()` runs each sandbox as a persistent Ubuntu VM on [Boat](https://boat.dev), with Node.js, Git, and Docker installed.

## Install

```package-install
npm i @opencoredev/sandbox-sdk@next @boatdev/sdk
```

The adapter needs `@boatdev/sdk` 1.9.9 or later. Set `BOAT_API_KEY` on your server, and keep it out of browser bundles.

## Quickstart

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { boat } from "@opencoredev/sandbox-sdk/boat";

await using box = await createSandbox(boat());
const result = await box.run("uname -a");
console.log(result.stdout);
```

`await using` deletes the VM when the block ends.

| Feature | Support | Notes |
| --- | --- | --- |

| Files | Yes | |

| Pause and resume | No | |

| Network policy | No | Only `"all"` |
| Hard lifetime (`timeoutMs`) | No | Boat's own one-hour auto-stop applies |

| Keys | Best-effort | Stored in the VM's display name |

## Run commands

Await `box.run` for the result, or iterate it to stream output as it arrives.

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { boat } from "@opencoredev/sandbox-sdk/boat";

await using box = await createSandbox(boat());
const result = await box.run("ls -la", { cwd: "/workspace", timeoutMs: 30_000 });
console.log(result.exitCode, result.stdout);

for await (const chunk of box.run("for i in 1 2 3; do echo $i; sleep 1; done")) {
  process.stdout.write(chunk.text);
}
```

A timeout or abort stops the command's process tree.

## Files

Relative paths resolve against `/workspace`.

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { boat } from "@opencoredev/sandbox-sdk/boat";

await using box = await createSandbox(boat());
await box.files.write("notes/todo.txt", "ship the docs\n");
console.log(await box.files.read("notes/todo.txt"));
console.log(await box.files.list("notes"));
```

## Background processes and previews

No ports to declare. The preview needs the `Cookie` header in `preview.headers` on every request. Treat it as a secret.

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { boat } from "@opencoredev/sandbox-sdk/boat";

await using box = await createSandbox(boat());
await box.start("npx serve -l 3000", { name: "web", ready: { port: 3000 } });
const preview = await box.preview(3000, { waitMs: 10_000 });
const response = await fetch(preview.url, { headers: preview.headers });
console.log(response.status);
```

## Pause, resume, and snapshots

This adapter has no pause, resume, or snapshots, and the methods don't exist on its sandbox type. Boat's native stop and snapshots are on `box.native.client`. Code that accepts any provider can check first:

```ts
import { createSandbox, hasCapability } from "@opencoredev/sandbox-sdk";
import { boat } from "@opencoredev/sandbox-sdk/boat";

await using box = await createSandbox(boat());
if (hasCapability(box, "pause")) await box.pause();
```

## Size, network, and lifetime

| Preset | Boat type | CPUs | Memory | Disk |
| --- | --- | --- | --- | --- |
| `small` | `small` | 2 | 4096 MiB | 12 GB |
| `medium` | `default` | 4 | 8192 MiB | 50 GB |
| `large` | `large` | 8 | 16384 MiB | 125 GB |

```ts
import { createSandbox } from "@opencoredev/sandbox-sdk";
import { boat } from "@opencoredev/sandbox-sdk/boat";

await using box = await createSandbox(boat(), { size: "large" });
```

Exact sizes, `network` other than `"all"`, `idleTimeoutMs`, and `timeoutMs` fail with `unsupported`. Boat's default one-hour auto-stop still applies. Configure longer sessions through Boat's native API.

## Configuration

| Option | Type | Default | Env var |
| --- | --- | --- | --- |
| `apiKey` | `string` | | `BOAT_API_KEY` |
| `baseUrl` | `string` | `https://boat.dev/api/v1` | `BOAT_API_BASE` |
| `machine` | `"small" \| "default" \| "large" \| "xlarge"` | `"default"` | |
| `requestTimeoutMs` | `number` | `90_000` | |

A per-create `size` wins over `machine`. `xlarge` (16 CPUs, 32 GB) needs a $100+ plan. `apiUrl` and `type` are deprecated aliases. `box.native` is `{ sandbox, client }`, Boat's sandbox metadata and the `BoatApi` client.

## Limitations

- Keys are best-effort, and the encoded key and labels must fit a 120-character name.
- No custom sizes, network policies, idle timers, hard lifetimes, pause, snapshots, or terminals.
- A native stop ends processes, and `/workspace` and `/tmp` records may not survive it.

## How it works

- Sandboxes are created with `noEnv: true`, so they get none of your account's saved secrets. `env` and `secrets` still apply.
- Boat has no labels, so the key and labels are compressed into the display name. Renaming the VM in Boat hides it from the SDK.
- Create retries up to three times with the same idempotency key. Commands and file operations are never replayed.
- Reads above 1 MiB use a signed download URL; smaller reads use guest commands.
- `destroy()` deletes the VM and its snapshots. Boat purges the data asynchronously.
