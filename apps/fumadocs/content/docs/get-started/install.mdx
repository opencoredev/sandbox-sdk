title: Install
description: Add Sandbox SDK and the adapter package you will create.
---

Install the SDK, then add the official SDK for any cloud adapter you call.

This page covers the package, runtime floor, and the first import.

```bash
bun add @opencoredev/sandbox-sdk
```

**Runtime**: Node.js 22 or 24, or Bun 1.3 or newer.

**Local**: included. No account.

**Memory**: included. No VM. Not a security boundary.

**Cloud adapters**: install the peer listed on that [adapter page](/docs/providers) and set its env vars. The CLI `sandbox-sdk doctor` reports which names are present. It does not print values.
