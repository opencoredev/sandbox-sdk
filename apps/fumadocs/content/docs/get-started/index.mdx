Start with what is portable, then install, then create.

This page is the ramp.

1. **[Compare](/docs/get-started/compare)**: files and commands are portable. Ports and snapshots are not.
2. **[Install](/docs/get-started/install)**: `bun add @opencoredev/sandbox-sdk`. Cloud adapters need their official SDK.
3. **[First sandbox](/docs/get-started/first-sandbox)**: `memory().create()` or `e2b().create()`.

`liveTest` is `null` for every shipped adapter. Railway is experimental.
