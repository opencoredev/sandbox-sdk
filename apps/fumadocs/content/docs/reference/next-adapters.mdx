## Gate

Do not file an adapter issue until all of these are yes:

- public docs
- files write/read and command exec
- official TypeScript client, or a stable HTTP API small enough to wrap
- credentials a user can mint
- not a general app-hosting product unless the sandbox subset is documented

Cloudflare shipped as a Worker-binding adapter. See [Cloudflare](/docs/providers/cloudflare).

Modal is deferred: Python files+exec exists, official TypeScript was not confirmed. See [Modal adapter map](/docs/reference/modal-adapter).

CreateOS (PR 9) stays off 1.0.0. See [CreateOS decision](/docs/reference/createos).

Blaxel is rejected for 1.0.0. Official SDK still exists. Closed PR 5 is not on the Sandbox 2 contract. See [Blaxel decision](/docs/reference/blaxel).
