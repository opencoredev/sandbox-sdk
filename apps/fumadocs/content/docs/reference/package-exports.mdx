The happy path is the adapter factory. `createSandbox({ provider })` stays for this major.

## Core

```ts
import {
  createSandbox,
  defineAdapter,
  withSandbox,
  supports,
  SandboxError,
} from "@opencoredev/sandbox-sdk";
import type {
  CreateSandboxOptions,
  SandboxAdapter,
  SandboxHooks,
  SandboxProvider,
  SandboxRuntime,
} from "@opencoredev/sandbox-sdk";
```

`defineAdapter()` lifts a runtime provider into `adapter.create()`. Hooks are opt-in and redact tokens.

## Adapters

```ts
import { memory } from "@opencoredev/sandbox-sdk/memory";
import { local } from "@opencoredev/sandbox-sdk/local";
import { e2b } from "@opencoredev/sandbox-sdk/e2b";
```

Also exported: `daytona`, `vercel`, `upstash`, `box`, `railway`, `cloudflare`. `agentos` is a deprecated alias for Local.

Memory is not a security boundary. Railway and Cloudflare are experimental. Every shipped adapter records `liveTest: null`.

## Metadata and testing

```ts
import { providers, getProviderMetadata } from "@opencoredev/sandbox-sdk/metadata";
import {
  posixConformanceCommands,
  requiredConformanceCases,
  runConformance,
} from "@opencoredev/sandbox-sdk/testing";
```

## CLI

The `sandbox-sdk` binary lists adapters, checks env names, and runs memory commands. It does not print secrets. See [CLI](/docs/guides/cli).

## Integrations

`/ai`, `/ai/harness`, `/eve`, and `/mastra` are optional peers. Railway and Cloudflare are not eligible.
