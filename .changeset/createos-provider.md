Add the CreateOS provider through `/createos`, with no required provider package. It supports keyed sandboxes, commands and streaming, files, background processes, previews, pause/resume, interactive terminals, resource selection, network allowlists, and idle auto-pause. Snapshots, template builds, hard sandbox lifetimes, and deny-all networking are not supported by this adapter.
