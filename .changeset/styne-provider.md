Add the Styne provider, `@opencoredev/sandbox-sdk/styne`: Styne microVMs through Styne's REST API with no peer package. Streamed commands whose timeout or abort kills the whole process group, files, previews with the traffic token header, pause and resume, named snapshots with `deleteSnapshot`, four sizes, `network: "none"`, hard and idle timeouts, and `box.native` on Styne's API, whose `sdk()` binds a caller-installed `styne-sdk`.
