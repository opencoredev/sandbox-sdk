Fixes from an SDK audit. Secret redaction across command output (`run()` stdout/stderr, async output iteration, `terminal.onData`, and `ProcessHandle.lines`/`logs`) and `SandboxError` metadata (`provider` and `sandboxId`) now handles secrets that overlap or lie inside `[REDACTED]` without mangling markers, leaking across chunk boundaries (for secrets up to the 1 MiB streaming hold cap; if a single held suffix exceeds 1 MiB, the held prefix is replaced with `[REDACTED]` and `truncated: true` is set while subsequent chunks process normally), or stalling on repeated prefixes, while keeping arrival order and stream attribution. Unrecovered secret-recovery failures withhold raw provider error text across all handle operations (including extensions) while preserving `code`, `retryable`, and `retryAfterMs`. `files.changes` validates the guest's tree ID before using it in a command. `files.upload` and `files.download` report a missing local path as `file_not_found`, a permission failure as `auth`, and a missing host `tar` as `unsupported`. Non-persistent Vercel no longer defines `pause` and `resume`. Agent tools throw `SandboxError` for a handle the SDK did not create. A background process start whose launch reply is lost (`outcome_unknown`) keeps its records, so a retry under the same name reports it as running instead of starting a second copy; `stop()` clears it. Corrupt process records fail with `invalid_argument`, and stream process start/restart reservations are shared across handles on the same provider. A process's guest-side `redact.sed` and companion `redact.txt` (written when any secret line exceeds 512 bytes) are removed when the process exits or is stopped; guest images with `awk` use a streaming carry window for boundary and wrapped-line matching, while images without `awk` fall back to POSIX `sh` whole-line holding up to 1 MiB (suppressing any single newline-less line past 1 MiB to `[REDACTED]` until the next newline or EOF) and wrapped-secret scrubbing. boxd and other gRPC errors keep their metadata. Local no longer kills a silent command after 30 seconds when Docker attaches without an upgrade, and an attach timeout stays `timeout`. `httpStatus` works on clients with a `cause` hook. The memory fake follows POSIX backslash rules.
