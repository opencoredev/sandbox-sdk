Fixes from an SDK audit. `Redactor.text` and streaming `chunkRedactor` now run to a fixed point (with linear-time marker-adjacent expansion) so secrets that overlap `[REDACTED]` or lie inside it neither mangle the marker nor survive across marker boundaries while staying idempotent, and `Redactor.error` scrubs `provider` and `sandboxId`. Unrecovered secret-recovery failures withhold raw provider error text across all handle operations while preserving `code`, `retryable`, and `retryAfterMs`. `files.read` keeps a leading UTF-8 BOM, so `files.edit` no longer drops it on providers that edit through read and write. `files.changes` validates the guest's tree ID before using it in a command. `files.upload` and `files.download` report a missing local path as `file_not_found`, a permission failure as `auth`, and a missing host `tar` as `unsupported`. `createSandbox` rejects an adapter that implements `pause`, `snapshot`, `terminal`, `deleteSnapshot` or `buildTemplate` without declaring the capability; non-persistent Vercel no longer defines `pause` and `resume`. Agent tools throw `SandboxError` for a handle the SDK did not create. Corrupt process records fail with `invalid_argument`, and stream process start/restart reservations are shared across handles on the same provider. A process's guest-side `redact.sed` is removed when it exits. boxd and other gRPC errors keep their metadata. Local no longer kills a silent command after 30 seconds when Docker attaches without an upgrade, and an attach timeout stays `timeout`. `httpStatus` works on clients with a `cause` hook. The memory fake follows POSIX backslash rules.
