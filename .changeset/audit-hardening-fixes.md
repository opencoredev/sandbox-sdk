Fixes from an SDK audit. Secret redaction across command output (`run()` stdout/stderr, async output iteration, `terminal.onData`, and `ProcessHandle.lines`/`logs`) and `SandboxError` metadata (`provider` and `sandboxId`) now handles secrets that overlap or lie inside `[REDACTED]` without mangling markers, leaking across chunk boundaries (for secrets up to the 1 MiB streaming hold cap; if a single held suffix exceeds 1 MiB, the held prefix is replaced with `[REDACTED]` and `truncated: true` is set while subsequent chunks process normally), or stalling on repeated prefixes, while keeping arrival order and stream attribution. Unrecovered secret-recovery failures withhold raw provider error text across all handle operations (including extensions) while preserving `code`, `retryable`, and `retryAfterMs`. `files.changes` validates the guest's tree ID before using it in a command. `files.upload` and `files.download` report a missing local path as `file_not_found`, a permission failure as `auth`, and a missing host `tar` as `unsupported`. Non-persistent Vercel no longer defines `pause` and `resume`. Agent tools throw `SandboxError` for a handle the SDK did not create. Corrupt process records fail with `invalid_argument`, and stream process start/restart reservations are shared across handles on the same provider. A process's guest-side `redact.sed` (and `redact.txt` when any secret line exceeds 512 bytes, used with `awk` for boundary carry and wrapped-line matching; images without `awk` hold incomplete lines whole up to 1 MiB until newline or EOF and suppress any single newline-less line past 1 MiB to `[REDACTED]` until the next newline or EOF so contiguous secrets are neither split across 4 KiB reads nor leaked across the cap) is removed when it exits or is stopped. boxd and other gRPC errors keep their metadata. Local no longer kills a silent command after 30 seconds when Docker attaches without an upgrade, and an attach timeout stays `timeout`. `httpStatus` works on clients with a `cause` hook. The memory fake follows POSIX backslash rules.
