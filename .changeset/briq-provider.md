Add the Briq provider: `briq()` from `@opencoredev/sandbox-sdk/briq`, built on the optional peer `@briq-cloud/sdk`. It runs commands, files, background processes, and private previews on one fixed image, with best-effort keys. It declares no pause, snapshot, size, network, or timeout support, so those options fail with `unsupported`.
