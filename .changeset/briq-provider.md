Add the Briq provider: `briq()` from `@opencoredev/sandbox-sdk/briq`, built on the optional peer `@briq-cloud/sdk`. It runs commands, files, background processes, and private previews on one fixed image, with best-effort keys. `size` takes the presets `small`, `medium` and `large`; it declares no pause, snapshot, network, or timeout support, so those options, and an exact size, fail with `unsupported`.
